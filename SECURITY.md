# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of SlapDash seriously. If you believe you have discovered a vulnerability, security bug, or data integrity issue on the global leaderboards, please report it responsibly.

### How to Report
- Please **do not** report security issues via public GitHub issues.
- Send an email to the project maintainer at `sithunyein.mailto@gmail.com`.
- Include detailed steps to reproduce the issue, along with any relevant browser and OS details.

### What to Expect
- Acknowledgement of your report within 48 hours.
- Regular updates on the status of the investigation and fix.
- Public attribution (if desired) after the fix has been deployed.
